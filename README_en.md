# Migrating a database from a third-party Redis cluster to a Yandex Managed Service for Valkey™ cluster

To transfer data from a third-party Redis source cluster to a [Managed Service for Redis](https://yandex.cloud/docs/managed-valkey) target cluster, create a logical dump to restore your data from it. See [this tutorial](https://yandex.cloud/docs/tutorials/dataplatform/valkey-data-migration) to learn how to prepare the infrastructure for Managed Service for Valkey™ using Terraform. This repository contains the configuration files you will need: [redis-cluster-non-sharded.tf](redis-cluster-non-sharded.tf) and [redis-cluster-sharded.tf](redis-cluster-sharded.tf).
